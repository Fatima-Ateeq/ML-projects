# Week 1 — Linux / Debian shell commands

These are commands for the Linux terminal (not Python). Try them in a Debian/Ubuntu terminal or WSL.

```bash
pwd                 # show current folder
ls                  # list files
cd folder_name      # enter a folder
cd ..               # go one folder up
mkdir practice      # create a folder
touch notes.txt     # create an empty file
cat notes.txt       # print file contents
head notes.txt      # first lines
cp notes.txt copy.txt
mv copy.txt renamed.txt
rm renamed.txt      # delete a file; use carefully
rmdir empty_folder  # remove an empty folder
whoami              # current user
ps                  # running processes
```

Some commands in the outline (such as `sudo`, `dpkg`, `shutdown`, and `kill`) can affect your system. Learn them with your instructor before using them.
